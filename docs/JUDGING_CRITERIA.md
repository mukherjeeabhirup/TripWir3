# Official HackUTD judging criteria

Source: Abhirup, supplied November 7, 2026 CST. The criteria below are preserved verbatim; no numerical weights were supplied.

> Innovation and Creativity (original idea, unexpected use of tech); Technical Complexity (complex algorithms/integrations); Completeness (works as intended, no major bugs or broken features); Design (user-friendly, visually appealing, intuitive); Impact (real problem, real-world use); Presentation (clearly explain problem, solution, technical choices).

Abhirup separately requires Completeness to be a hard project release gate. The implementation of that rule and the criteria-to-evidence map are in [RESEARCH_PLAN.md](RESEARCH_PLAN.md).
