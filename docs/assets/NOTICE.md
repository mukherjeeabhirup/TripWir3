# Logo sources and attribution

These two official logo files are stored in their original formats and remain byte-for-byte identical to the downloads. Their colors and proportions are unchanged. The architecture SVG embeds the NVIDIA PNG and the FastAPI vector artwork without fetching external assets; the README uses a PNG export for reliable GitHub rendering. White background panels preserve the black NVIDIA wordmark's contrast within the dark diagram on both light and dark pages.
